# 🚗 Tabaria e Adega Fogo na Bomba - Digital Loyalty Card

A digital loyalty card web system tailored for the beverage and convenience store industry. Designed to replace paper loyalty cards, automate customer retention, and streamline store management.

## ✨ Features
* **Secured Admin Dashboard:** Complete management of campaigns, rewards, and customer database.
* **Cashier / Stamp Validator:** Quick search by phone number or card ID to add or remove stamps.
* **Customer Digital Card:** Modern, responsive UI with real-time progress tracking and automated reward celebration modals.
* **WhatsApp Integration:** Instant messaging dispatch containing the client's direct card link.
* **Birthday Tracking:** Monitor customer anniversaries for special campaigns.

## 🛠️ Tech Stack
* HTML5 / CSS3 (Tailwind CSS)
* Vanilla JavaScript
* Firebase Firestore (Cloud database persistence)
* QRCode.js / FontAwesome

# 🚗 Tabaria e Adega Fogo na Bomba - Fidelidade Digital

Sistema web de cartão fidelidade digital voltado para o setor de tabaria e adega. Desenvolvido para eliminar o uso de cartões de papel, fidelizar clientes de forma automatizada e facilitar o controle do lojista.

## ✨ Funcionalidades
* **Painel Administrativo Protegido:** Gestão completa de campanhas, prêmios e visualização da base de clientes.
* **Validador de Caixa / Carimbos:** Sistema rápido para buscar clientes por telefone ou ID e adicionar/remover selos.
* **Cartão Digital do Cliente:** Visual moderno, responsivo, com progresso em tempo real e notificação de prêmio conquistado.
* **Disparo via WhatsApp:** Envio automatizado de mensagens contendo o link direto do cartão do cliente.
* **Gestão de Aniversários:** Acompanhamento de datas comemorativas dos clientes.

## 🛠️ Tecnologias Utilizadas
* HTML5 / CSS3 (Tailwind CSS)
* JavaScript Puro (Vanilla JS)
* Firebase Firestore (Persistência de dados em nuvem)
* QRCode.js / FontAwesome
